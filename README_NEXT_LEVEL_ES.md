# Academic 360 Next Level — Odoo 18

Suite SIS/ERP académico integral. Esta versión amplía Academic 360 Enterprise con experiencia estudiantil inspirada en portales universitarios modernos y reglas de matrícula ejecutables.

## Ciclo de vida cubierto
Prospecto/CRM → admisión → documentos → convalidación → estudiante → plan/malla versionada → oferta/secciones → matrícula → docencia/LMS → evaluación/notas/asistencia → expediente/progreso → trámites → finanzas/becas/planes de pago → bloqueos → graduación.

## Motor académico
- Planes de estudio versionados, niveles, créditos, obligatorias/electivas, correquisitos y prerrequisitos.
- Curso: duración en semanas, créditos, horas de contacto, independientes y laboratorio, sílabo, resultados de aprendizaje, metodología y bibliografía.
- Reglas de elegibilidad: prerrequisitos, créditos mínimos, promedio mínimo, bloqueos, cupos y choques de horario estructurados.
- Secciones por periodo, modalidad, profesores, sede/aula, bloques horarios, cupo y lista de espera.
- Intentos/repetición, retiro, nota final, aprobado/reprobado, progreso evaluado del curso.
- Indicadores: créditos cursados/aprobados/pendientes, promedio ponderado y avance de carrera.

## Portal del estudiante
- Dashboard académico con progreso, promedio, créditos, cursos y bloqueos.
- Plan de estudios visual por periodo y estado de cada materia.
- Matrícula en línea con validaciones automáticas.
- Cursos activos con porcentaje evaluado, nota, evaluaciones y tareas.
- Expediente/calificaciones.
- Solicitudes y catálogo de trámites.
- Base financiera existente: cargos, becas, planes de pago y facturación Odoo.

## Roles
Admisiones, Dirección, Caja, Registro Académico, Profesor, Administrador y usuario/portal según las reglas de seguridad del módulo.

## Integraciones
Conectores configurables para Moodle, Canvas LMS, Microsoft Teams/Education, Google Classroom, Blackboard y API personalizada. Las APIs reales requieren credenciales/OAuth de cada institución.

## Nota
La suite es una base funcional extensible. Procesos regulatorios, reglas financieras, calendarios y políticas académicas deben parametrizarse según cada institución antes de producción.

# Portal Docente 360

Incluye dashboard docente, cursos/secciones asignadas, lista de estudiantes, avance, libro de calificaciones tipo matriz, evaluaciones ponderadas, publicación de notas, flujo de acta, asistencia diaria, tareas/entregas y retroalimentación, además de seguridad por profesor y base para rectificaciones auditadas.

Ruta principal: `/my/professor`.

El usuario debe estar vinculado a `academic.professor.user_id`. Los profesores solo pueden operar las secciones que tienen asignadas.

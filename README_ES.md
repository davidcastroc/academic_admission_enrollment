# Suite Académica 360 — Odoo 18

Evolución integral del módulo de admisión y matrícula. Incluye admisiones, expediente estudiantil, programas, periodos, oferta académica, cursos, secciones, profesores, matrícula por curso, lista de espera, evaluaciones ponderadas, libro de calificaciones, publicación de notas, asistencia, tareas/entregas, anuncios, portal estudiantil e integraciones educativas configurables.

## Roles
- **Estudiante (Portal):** admisión, documentos, matrícula en línea, cursos activos, expediente y calificaciones publicadas.
- **Profesor:** secciones, evaluaciones, notas, asistencia, tareas y anuncios.
- **Registro académico:** matrícula por curso y control académico.
- **Admisiones / Dirección / Caja / Administración:** se mantienen y amplían los roles existentes.

## Integraciones
Se incluye un registro seguro de conectores para Moodle, Canvas LMS, Microsoft Teams/Education, Google Classroom, Blackboard y API personalizada. La autenticación OAuth/API y los endpoints concretos deben configurarse con las credenciales de cada institución/proveedor antes de sincronizar datos reales.

## Idioma
La interfaz nueva se entrega directamente en español y conserva compatibilidad con el sistema de traducciones estándar de Odoo para despliegues multidioma.
